# Infrastructure

Репозиторий для управления инфраструктурой, Kubernetes-кластерами, служебными компонентами платформы и процессами развертывания приложений.

## О репозитории

Данный репозиторий содержит инфраструктурный код, конфигурации и tooling, необходимые для:

- развертывания Kubernetes-кластеров;
- управления инфраструктурой платформы;
- развертывания приложений;
- поддержки GitOps-подхода;
- управления observability-стеком;
- автоматизации инфраструктурных процессов;
- управления Helm chart-ами и Helmfile-конфигурациями;
- хранения Docker-конфигураций и контейнерных образов;

Репозиторий выступает центральной точкой управления инфраструктурой всех приложений.

---

# Используемые технологии

## Kubernetes

Основная orchestration-платформа для запуска приложений и служебных компонентов.

## Helm

Используется для пакетирования и шаблонизации Kubernetes-манифестов.

## Docker

Используется для сборки и запуска контейнеров.

## Prometheus

Используется для сбора метрик и мониторинга.

## Loki

Используется для агрегации и хранения логов.

## Vault

Используется для управления секретами.

## External Secrets Operator

Используется для синхронизации секретов из внешних secret backend-ов.

## Harbor

Используется как приватный container registry.

---

# Безопасность

Рекомендуется:

- не хранить секреты в Git;
- использовать Vault и External Secrets Operator;
- ограничивать RBAC;
- использовать private registry;
- включать image scanning;
- использовать branch protection rules;
- применять least privilege principle.

---

# Требования

Для работы с репозиторием рекомендуется наличие:

- Git
- Docker
- Docker Compose
- kubectl
- Helm
- Helmfile
- Kubernetes cluster
